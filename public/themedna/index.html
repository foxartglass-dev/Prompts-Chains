FAQ

Questions? Answers.

Everything you need to know about Theme DNA.

How does it actually work?

You paste a URL (or upload a screenshot). Our AI takes a screenshot, analyzes every visual element — colors, fonts, spacing, shadows, border radius, button styles — and outputs a structured design system. Then we generate complete theme files for Astro and/or WordPress/Elementor using those exact design tokens.

Is this just a template with my colors swapped in?

No. We extract the complete design DNA — not just colors, but typography scale, spacing density, component styles, shadows, and border treatments. The result feels like the original site's design system, applied to a complete set of pages.

What if I don't have a website yet?

Use any website as inspiration. See a competitor's site you like? A brand with great design? Paste their URL and get a theme that captures their design quality, then customize the content to make it yours.

Can I edit the generated pages?

Absolutely. Astro themes are standard .astro files with CSS custom properties. WordPress themes are Elementor JSON — edit everything in Elementor's drag-and-drop builder. You own all the code.

Do I need to know how to code?

For WordPress/Elementor: zero coding required. Paste a URL, get pages, edit in Elementor. For Astro: basic familiarity with npm and project setup helps, but the theme is a standard integration that just works.

Is there a monthly fee?

No. You pay once, own it forever. No subscriptions, no usage limits, no surprise charges. The Pro tier is $97 one-time.

Can I use this for client work?

The Pro license covers your own projects. For client work and white-labeling, grab the Agency license at $297. It includes bulk extraction, client-ready exports, and bonus marketing assets.
