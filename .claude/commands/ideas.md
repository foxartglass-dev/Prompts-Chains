The user has an idea they want to capture. Your job:

1. Ask them to describe the idea briefly (if they haven't already)
2. Add it to `docs/IDEAS-BACKLOG.md` with:
   - Today's date
   - Brief description
   - Category (new app / feature for existing / improvement)
3. Confirm it's captured
4. Return to whatever task was in progress

Do NOT:
- Start working on the idea
- Research the idea
- Discuss implementation details
- Get distracted from current work

Just capture it and move on. Ideas are valuable but chasing them kills productivity.
