== Description ==

**Theme DNA Generator** analyzes any website and creates a complete set of matching Elementor page templates for your WordPress site.

**How it works:**

1. Paste a website URL
2. Theme DNA extracts the design DNA — colors, fonts, spacing, card styles, button styles
3. Get a full set of Elementor pages that match the original site's look and feel
4. Import directly into WordPress with one click
5. Customize further in Elementor

== Installation ==

1. Upload the plugin to the `/wp-content/plugins/` directory
2. Activate through the 'Plugins' menu in WordPress
3. Make sure Elementor is installed and active
4. Go to Elementor > Theme DNA in the admin menu
5. Paste a URL and click Generate

== Frequently Asked Questions ==

= Do I need Elementor Pro? =

No. Theme DNA Generator works with the free version of Elementor.

= Is this legal? =

Yes. Theme DNA extracts design patterns (colors, fonts, spacing) — not content, images, or code. It's the same as a designer using a mood board for inspiration.

= How long does generation take? =

About 10 minutes for a full site. The tool analyzes the design, extracts the style DNA, and generates each page template individually.

= Can I customize the pages after import? =

Absolutely. Pages are imported as standard Elementor pages. You can edit everything in the Elementor visual editor.
